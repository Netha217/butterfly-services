# Butterfly Service

**Butterfly Service** est un site de prestation de services touristiques, conçu pour permettre aux utilisateurs de découvrir les merveilles d'Abidjan et de la Côte d'Ivoire.

## Fonctionnalités

- **Galerie d'images** : Une galerie visuelle des lieux touristiques emblématiques, comme le Stade Olympique Alassane Ouattara.
- **Formulaire de contact** : Une manière simple de nous joindre pour toute demande ou réservation.

## Technologies utilisées

- **HTML** et **CSS** pour la structure et le style.

## Déploiement sur GitHub Pages

1. Rendez-vous sur [GitHub](https://github.com).
2. Clonez ou téléversez ce dépôt.
3. Activez GitHub Pages dans les paramètres du dépôt en sélectionnant la branche principale.

Le site sera disponible à l'URL : `https://<votre-utilisateur>.github.io/butterfly-service/`
